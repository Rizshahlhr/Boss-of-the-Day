Boss of the Day is a fast arcade boss-fight game for Android, built with Flutter. Each fight lasts up to 90 seconds and is played with one thumb. A new boss is generated from the date, so everyone gets the same challenge, with no server needed.
Features
Daily boss: a new boss every day, one attempt only
Practice mode: unlimited fights against random bosses
3-phase fights: attacks get harder as the boss weakens
Hidden weakness: shoot the glowing eye when it opens for triple damage
Power-ups: shield and rapid fire
Bomb: clear all bullets and damage the boss (once per fight)
Streaks: beat the daily boss on consecutive days to build your streak
Coins and upgrades: spend coins on faster fire rate and extra lives
Ship skins: unlocked at 3, 7, and 14-day streaks
Share your result: copy a result card and challenge friends
